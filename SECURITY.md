# Sicherheitsrichtlinie

## Unterstuetzte Version

Sicherheitskorrekturen werden derzeit nur fuer das neueste auf GitHub veroeffentlichte MVP-Pre-release geprueft.

## Sicherheitsproblem melden

Bitte keine Sicherheitsluecken als oeffentliches Issue melden. Verwende im GitHub-Repository **Security** > **Report a vulnerability**, damit Details privat uebermittelt werden koennen.

Bitte beschreibe betroffene Version, reproduzierbare Schritte, moegliche Auswirkungen und bekannte Umgehungen. Keine echten API-Keys, Manuskripte oder sonstigen vertraulichen Daten mitsenden.

Allgemeine Fehler und Funktionswuensche gehoeren in die oeffentlichen GitHub Issues.
